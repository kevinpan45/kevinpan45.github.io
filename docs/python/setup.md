# Python use in Ubuntu 24.04

***Python3 is the system built-in software***

1. Install Pip

```bash
apt install python3-pip
```

2. Install venv

```bash
apt install python3-venv
```

3. Create venv

```bash
python3 -m venv opendal_env
```

4. Install package in venv

```bash
pip3 install opendal
```
