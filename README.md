# kevinpan45.github.io

1. Write book

Switch to docs branch, write docs and push

2. Install MkDocs

```bash
apt install mkdocs
```

Install plugins

- [mkdocs_puml](https://github.com/MikhailKravets/mkdocs_puml)

```bash
pip install mkdocs_puml
```

3. Deploy to GitHub Page

```bash
mkdocs gh-deploy
```
